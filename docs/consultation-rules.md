# 相談案内とLINEキーワードの判定

更新日: 2026-11-02

## 購入前（自己肯定感版・ハートの欠け版共通）

- 最優先は相談者本人の年収。従来の下限である300万円以上を対象とする。
- 自分または彼が既婚の回答は、本人の年収に関係なく対象外にする。
- 未成年は対象外。25歳未満や職業だけでは一律に除外しない。
- ブロック・連絡先なしは、それだけでは除外しない。連絡経路がある場合に優先度を加点する。
- 彼の年収や自己肯定感の点数は、相談対象の判定に使用しない。
- 対象者のLINEキーワードは「未来設計」、対象外は「後悔しない」。

### 管理用の優先度点

ユーザーの指定した優先順位を実装するための運用上の重みであり、復縁の確率を表すものではない。

| 本人年収 | 年収点 |
| --- | ---: |
| 200万円未満・分からない | 0 |
| 200〜249万円 | 20 |
| 250〜299万円 | 40 |
| 300〜349万円 | 70 |
| 350〜399万円 | 75 |
| 400〜449万円 | 80 |
| 450〜499万円 | 85 |
| 500万円以上 | 90 |

| 連絡経路の回答 | 加点 |
| --- | ---: |
| LINE・LINE以外のSNSや電話で連絡できる | 10 |
| 連絡先は分かるが連絡しづらい | 8 |
| 職場・学校・共通の知人などで接点がある | 5 |
| ブロックされ直接連絡できない・連絡先が分からない | 0 |

年収点に連絡経路加点を足し、既存のGoogle Formsの診断結果欄へ「相談見込み点」「本人年収点」「連絡経路加点」を記録する。連絡経路の加点で年収条件や既婚の除外を覆すことはない。

## サポート受講生

自己肯定感版のみ、LINEキーワードを「購入者診断」から「彼との復縁を叶える」に変更。表示・コピー・回答データのCTA名を一致させる。購入者表示用の抽出条件に使っている「対象:購入者」は維持する。ハートの欠け版の受講生キーワードは従来どおり「購入者診断」。

## 検証

- ローカルブラウザで両コンセプトの年収・連絡経路・既婚状況・年齢・職業の組合せを確認。
- 受講生版の表示・コピー・送信データを確認。320px幅で横はみ出しなし。
- 送信処理はテスト中に捕捉し、本番の回答シートにはテスト回答を送信していない。
